Tiny Island Survival

Sinh tồn trên đảo nhỏ: chặt cây, dựng trại, cứu người lạc, vượt bão, ra khơi tìm xác tàu và giải mã tín hiệu cổ. Chơi hoàn toàn offline.

Phiên bản 0.50.0 · bản thử nghiệm (chưa lên Google Play)

Android

Android 7.0 trở lên, điện thoại 64-bit. ~54 MB.

Tải APK
  1. Mở file vừa tải.
  2. Nếu máy hỏi, cho phép trình duyệt “Cài ứng dụng không rõ nguồn gốc”.
  3. Bấm Cài đặt. Từ bản 0.35.0, game tự báo khi có bản mới và tải giúp bạn; save game được giữ.

Windows

Windows 10/11, 64-bit. ~39 MB (ZIP).

Tải cho Windows
  1. Giải nén file ZIP.
  2. Mở TinyIslandSurvival.exe.
  3. Nếu SmartScreen cảnh báo: More info → Run anyway (bản chưa ký số).

Bản thử nghiệm: có thể còn lỗi và số liệu chưa cân bằng. Game không cần mạng, không thu thập dữ liệu cá nhân.

Kiểm tra file (SHA-256)

So với kết quả certutil -hashfile <file> SHA256 (Windows) để chắc file tải về nguyên vẹn.
